# Cake Shop Website

This is a simple and responsive Cake Shop website built using HTML, CSS, and basic JavaScript.

## Features

- Responsive layout
- Product listings for cakes
- Clean and modern design
- Basic interactivity with JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript (vanilla)

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
